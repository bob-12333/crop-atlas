Crop Atlas — Standalone Edition (No Users / No Database)

index.html contains the interface and styles.
app.js contains the 3D map, data requests, crop recommendations, rearrangeable 3-window layout, and mobile navigation.

Keep both files in the same folder.
Open that folder in VS Code (Live Server), or run:
  python3 -m http.server 8000
inside the folder and open http://localhost:8000 in your browser.
